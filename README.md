# Portfolio Starter

This is a minimal static portfolio you can deploy with GitHub Pages.

## How to use
1. Rename the folder/repo to `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Push to GitHub.
3. In **Settings → Pages**, ensure the Source is set to `Deploy from a branch`, Branch: `main` and `/ (root)`.
4. Edit `index.html` to add your content. Replace email/LinkedIn links and add your CV PDF to `assets/`.
